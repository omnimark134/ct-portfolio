Project 1: My Portfolio Website

Reflection

What a harrowing and exciting journey it has been making this website. I have undergone many ups and downs, a last day reboot and lock in, brain farts and making trillions upon trillions of mistakes due to an extra comma. I am extremely happy with the way my website has turned out, mimicking my interests and being unique in a way I find satisfying.HTML, I utilised CSS, Visual Studio Code, Git and GitHub in order to build my website by constantly pushing and committing in order to track progress and make my website look more appealing. Skills I utilised included occasionally appealing to artificial intelligence to teach me ways I could better my code or explain a new concept to myself. I believe visual studio code and css played an important role in the development of my website as it allowed for a platform to code on. Things I learned from this project includes adding shadow to text, adding music buttons, mastering navigation and list functions. Things I could do better in the future include adding much more background images and perhaps moving or interactive functions. Ways I made my website unique include utilisation of an overall theme, namely Jojo’s bizarre adventure in order to captivate and convey my individuality in the class. I also learned how to style my button to make it interactive and unique rather than a simple circle or square that does not move when clicked. Another thing I could improve on in the future includes managing my time better and observing my code much better before I test it. This will ensure my layout is much more smooth and even throughout and ensure that I have more time to work through my code and refine it better. Pieces of my code that have been difficult to do include colour mixing; finding the right colour that mixed my overall theme and sticking to it.
