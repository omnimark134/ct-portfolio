Project 3: Arduino Custom Display

My project this term was to create a working arduino display. This meant that I was to use the arduino and TFT 2 '4 display to display a working clock, customized using vs code python and arduino code myself. This took a substantial amount of time to figure out primarily due to the immense amount of files required to download into the library such as MCU and Adafruit. I have chosen to have my design vertical and adopted a ‘cyberpunk’ inspired design, choosing to capture essence with unique font choice as well as selective colour scheming. I faced many issues during this project, including poor time management, limited help, and repeating the same mistakes over and over again leading to each lesson becoming a loop of the previous. I had overcome this in the last few lessons by resorting to Educhat to explain certain concepts and pieces of code in order for me to continue expanding and personalizing my code. It is important to note that I made substantial changes to my vs code python and my arduino code. Choosing both to minimise some and build on the existing code provided in order to succeed. What worked was eventually learning the importance of constantly verifying and uploading my arduino code to improve clarity and ensure that I would not discover an abundance of errors. What did not work however, was in class explanations, I felt as if sometimes the code was just given to copy paste and occasionally I did not understand the importance of each line. This was eventually fixed through ai and educhat, allowing me to build on my own code with the appropriate knowledge. One thing I learned through this process is the importance of commenting code, this allows me to pick up where I left off and make sure that my progress remains smooth and easy to understand after long breaks or periods without working.
